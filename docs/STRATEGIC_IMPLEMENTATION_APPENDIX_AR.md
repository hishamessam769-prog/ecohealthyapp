# ملحق التنفيذ للخطة الاستراتيجية 2027–2029

تم الحفاظ على ملف الخطة ذي 48 صفحة داخل `docs/` وربطه بالمنتج بدل تحويله إلى وثيقة منفصلة. محاور الاستقلال المؤسسي أصبحت: هوية وصلاحيات مستقلة، دورة طلب-تحصيل-تنفيذ قابلة للتدقيق، استحقاق وإيراد مؤجل، عمولات ناضجة لا تعتمد الفاتورة الخام، تشغيل Kitchen/QA/Delivery، وKPI snapshots موثقة التعريف.

قرارات الحوكمة في الخطة تظهر تقنيًا في: effective-dated roles، approved plan versions، immutable journals/invoices، audit/outbox، certified investor metrics، وملكية حسابات Supabase/Vercel/Repository باسم ECO Healthy. لوحات CEO وInvestor لا تستعمل أرقامًا تجميلية؛ كل نسبة تحمل numerator/denominator/version/freshness/status.

هذا الملحق هو نقطة تتبع التنفيذ. أي توصية جديدة من الخطة تُضاف كـMigration + Permission + API + Test + Documentation قبل اعتبارها مكتملة.
